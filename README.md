# Scratch2Build — Session 3

## CSS Layout & Responsive Design Workshop

Welcome to the Scratch2Build CSS Layout workshop!

In this session, you will learn how CSS controls page layout and how to build responsive interfaces using Flexbox, CSS Grid, and media queries.

The session combines technical explanations with practical exercises to help you apply what you learn.

## Learning Objectives

By the end of this session, you should be able to:

* Understand the CSS Box Model: content, padding, border, and margin.
* Understand the difference between `content-box` and `border-box`.
* Use Flexbox to align and arrange elements.
* Understand the main axis and cross axis in Flexbox.
* Use CSS Grid to create flexible layouts.
* Use responsive design techniques to support smaller screens.
* Use Chrome DevTools to inspect and debug CSS layouts.
* Understand how to submit your work through GitHub Pull Requests.

## Session Topics

### 1. CSS Box Model

Learn how content, padding, borders, and margins affect an element's size and spacing.

### 2. Flexbox

Practice using:

* `display: flex`
* `justify-content`
* `align-items`
* `flex-wrap`

### 3. CSS Grid

Learn how to arrange dashboard cards in a flexible grid using techniques such as:

`repeat(auto-fit, minmax(280px, 1fr))`

### 4. Responsive Design

Learn how to make layouts adapt to different viewport sizes and avoid unwanted horizontal scrolling.

### 5. Chrome DevTools

Use browser developer tools to inspect elements, understand the Box Model, and debug layout issues.

## Practical Activities

During the session, you will:

* Fix an alignment problem in a modal card.
* Practice aligning elements with Flexbox.
* Explore responsive CSS Grid layouts.
* Review code and discuss Pull Request feedback.
